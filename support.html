Support

Something not working? Start here — most issues are one of the five below.

1. Nothing is recorded (0 MB file)

The source produced no video, so there is nothing to save. This happens when you share a window and that window is minimized or closed. Share the entire screen instead, or keep the shared window visible.

2. The saved file shows 0:00

Files saved before version 0.5.0 had no duration. Re-save with a current version — recordings now get the correct duration written at save time.

3. MP4 is not available

Some Chrome builds do not ship the MP4 encoder. The settings page tells you when this happens and falls back to WebM automatically.

4. The microphone does not record

Microphone is off by default. Turn it on in the settings page and accept the browser prompt. If the prompt never appears, allow microphone access for Chrome in your system privacy settings.

5. A recording was lost after a crash

Open the recorder window — unfinished recordings are listed there and can be saved. The file is written continuously while recording, so a crash should leave a playable file behind.

Still stuck? Send diagnostics

Open the settings page and click Copy diagnostics. It contains the extension version, your browser and OS, your settings and the last error — never any recording content. Paste it into your email.
